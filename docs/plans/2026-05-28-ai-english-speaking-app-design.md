# AI 영어 스피킹 앱 — 설계 문서

- 작성일: 2026-05-28
- 상태: 설계 확정 (구현 계획 단계로 진입 가능)

## 1. 북극성 (North Star)

> "영어 공부 앱"이 아니라, 학생이 **부담 없이 매일 영어로 이야기하게 만드는 AI 친구**.

학교 시험용 영어가 아니라 "실제로 영어를 말할 수 있게" 만드는 것이 목적이다. 평가받는 느낌을 0에 가깝게 만들고, 친구와 대화하는 경험을 제공한다.

## 2. 타겟 사용자

- 1차: 작성자의 두 딸 (중·고등학생 여자아이)
- 확장: 비슷한 또래 학생들 (MVP 검증 후)

## 3. 목표 / 범위

- **궁극 범위**: MVP로 두 딸에게 먼저 검증 → 반응이 좋으면 상용화 검증.
- **설계 원칙**: 지금 빠르게 만들되, 나중 확장을 막지 않는다. 단, 확장용 인프라를 미리 짓는 과잉설계는 피한다.
- **확장 가능하게 잡는 곳은 딱 둘**:
  1. 페르소나를 "코드"가 아닌 "데이터"로 분리
  2. 음성 처리를 "브라우저 내장"이 아닌 "서버 경유"로 분리
- 나머지(UI·인증)는 일부러 가볍게.

## 4. 플랫폼

- **웹 PWA** (휴대폰 브라우저, "홈화면에 추가"로 앱처럼 사용).
- HTTPS 필수 (마이크 권한 조건).
- iOS/Android 구분 없이 동작. 나중에 네이티브 앱으로 확장 시 서버 로직 재사용.

## 5. 음성 아키텍처 — 조립형(Composed)

MVP 1차는 **조립형(A)** 으로 시작한다. 교정·레벨조절 통제가 쉽고 저렴하다.

```
[브라우저] 마이크 녹음(MediaRecorder)
   │ 오디오 → 서버
   ▼
[서버] ── STT (음성→텍스트)
   │
   ├── 대화 LLM: 페르소나 + 레벨적응 + 리캐스트 응답 생성
   │
   └── 교정 LLM(별도): 틀린 점만 수집 → 세션 끝 요약
   ▼
[TTS] 응답 음성화
   ▼
[브라우저] 음성 재생 + 교정은 세션 끝 카드로 표시
```

- 지연: STT(~0.7s) + LLM 첫 단어(~1s) + TTS(~0.5s) ≈ 2~3초. 스트리밍으로 체감 단축.
- **보안 원칙**: AI API 키는 절대 브라우저에 두지 않는다. 서버가 키를 쥔다.
- **향후 업그레이드**: 대화 부분만 실시간 음성 API(OpenAI Realtime / Gemini Live, WebRTC 기반)로 교체. 서버 구조는 유지.

### 5.1 음성 전송 오버헤드 & 지연 (검토 결과)

"음성을 서버로 보내 처리하면 오버헤드 아닌가?"에 대한 정리:

- **우리 서버는 음성을 직접 연산하지 않는다.** 무거운 STT/LLM/TTS는 AI 제공사 인프라에서 돈다. 우리 서버는 키를 쥐고 흐름을 중계·조율하는 **얇은 오케스트레이터**다. (우리 서버 CPU 부하 아님)
- **음성 데이터는 작다.** 브라우저 Opus 코덱 기준 말소리 ≈ 16~32 kbps → 10초 발화 ≈ 20~40 KB (사진 1장보다 작음). 업로드 대역폭 부담은 미미하다.
- **진짜 지연 주범은 전송이 아니라 "모델이 생각하는 시간"** (≈ 1~2초). → **스트리밍**으로 해결:
  - 올려보내기: 말하는 동안 오디오를 청크로 흘려보냄(끝까지 안 기다림).
  - 내려받기: LLM 첫 단어 → 바로 TTS로 재생 시작(완성 안 기다림).
  - 체감 2~3초 → 1초 안팎.
- **우리 서버를 거치는 hop**: 수십 ms 수준(가까운 리전). 모델 1~2초 대비 무시할 만하며, 그 대가로 키 안전 + 교정/레벨 로직 삽입 통제력을 얻는다.
- **더 줄이려면(나중)**: 임시 토큰(ephemeral token)으로 브라우저↔제공사 직결 → hop 제거. 이는 실시간 음성 API(B)가 동작하는 방식이므로, B로 업그레이드 시 구조적으로 해소된다.

→ **결론**: MVP는 조립형 + 스트리밍이 맞다. 전송 오버헤드는 작고, 지연은 스트리밍으로, hop은 나중에 직결로 제거 가능.

## 6. AI 페르소나 — "데이터"로 설계

대화 엔진은 하나만 만들고, 페르소나는 끼워 넣는 **설정 묶음**으로 둔다.

```json
{
  "id": "mia",
  "name": "Mia",
  "voice": "shimmer",
  "age": "peer | older-sister | tutor",
  "personality": "밝고 K-pop 좋아하는 또래 친구. 리액션 큼.",
  "correctionStyle": "gentle"
}
```

- MVP: **잘 만든 프리셋 2~3개** (예: 또래 친구 / 쿨한 언니). 아바타는 간단한 이미지·이모지.
- 페르소나 추가 = "프롬프트 글 + 목소리 ID" 작업. 새 기능 개발이 아님.
- 무한 커스텀(외모·성격 자유 조합)은 **나중으로 미룸**.

## 7. 레벨 진단 & 난이도 조절

- **진단**: 별도 시험 없음. 첫 진입 시 AI가 3~5턴 자연스럽게 대화하며 문장 길이·어휘 다양성·문법 정확도·유창성을 LLM이 평가 → 레벨 추정·저장.
- **레벨 노출 정책**: **숨김.** 아이는 레벨(숫자/등급)을 보지 않는다. AI가 내부적으로만 알고 난이도를 조용히 맞춘다. ("평가받는 느낌" 제거)
- **성장은 따로**: 긍정형 성장 리포트로만 보여준다 (아래 9.4).
- **하나의 레벨 값이 세 가지를 동시에 움직임**:
  - 어휘 범위 / 문장 복잡도
  - 말하기 속도 (TTS 속도)
  - 한국어 보조량 (아래 8)

## 8. 한국어 스캐폴딩(비계) 정책

- **레벨별 자동 조절**: 초급엔 한국어 힌트를 더 주고, 실력이 늘수록 점점 걷어내 순수 영어로.
- 숨김 레벨 시스템과 맞물려 동작 (별도 기능 아님 — 프롬프트 규칙).
- **항상 '도와줘 / 힌트' 탈출구 제공**: 아이가 "어떻게 말하지?"에서 멈추지 않고 계속 가게 하는 안전망.

## 9. 교정 & 리텐션 UX

### 9.1 교정 — 리캐스트 + 세션 끝 요약
- **대화 중**: 빨간 줄 금지. AI가 답하면서 올바른 형태를 자연스럽게 되돌려준다 (recast).
  - 예) 아이: "I go to concert yesterday" → AI: "Oh, you **went to a concert** yesterday? Who did you see?"
- **세션 끝**: 교정 LLM이 모은 항목 중 2~3개만 "Today's tips" 카드로 살짝.

### 9.2 AI 기억 / 연속성 (리텐션 핵심)
- 관심사·최근 화제를 DB에 저장 → 매 대화 시작 시 프롬프트에 주입.
- "지난번에 말한 ○○ 어떻게 됐어?" → 챗봇이 아니라 진짜 친구처럼 느껴지게.

### 9.3 대화 모드 다양성
- 같은 음성 엔진 위에 모드만 교체: 자유수다 + 오늘의 질문 (+ 가벼운 역할극 1개).
- 모드 = 프롬프트 템플릿 차이라 구현 부담 적음.

### 9.4 부드러운 데일리 초대 + 성장 리포트
- 협박형 스트릭 대신 부드러운 초대 ("Mia가 궁금한 게 생겼대 👀").
- 주간 리포트: "이번 주 새로 쓴 표현 N개" 같은 긍정형 성취감.

## 10. 엔진 선택 (MVP)

- **한 벤더로 통일** (예: OpenAI로 STT·LLM·TTS). SDK·키·청구가 하나 → MVP 속도 최우선.
- **TTS만 나중에 교체 가능**하도록 추상화 (목소리 캐릭터성이 약하면 ElevenLabs 등으로 스왑).
- 정확한 모델명·요금·정책은 변동이 크므로 **구현 단계에서 최신 문서로 확정**.

## 11. 데이터 모델 (개략)

- `student`: id, (숨김)level, 진단 메타
- `interests`: 학생별 관심사 태그 + 최근 화제 메모 (기억용)
- `personas`: 프리셋 설정 데이터
- `sessions`: 대화 기록, 교정 항목, 사용 표현 (성장 리포트 산출용)

## 12. 핵심 UX 원칙 (10대 대상)

1. 대화 도중엔 절대 "틀렸다"고 표시하지 않는다.
2. 레벨·점수 같은 평가 지표를 본인에게 노출하지 않는다.
3. 막혔을 때 빠져나갈 길(힌트/한국어)을 항상 준다.
4. 성장은 긍정형으로, 따로, 가끔.

## 13. 일부러 나중으로 미루는 것 (YAGNI)

- 실시간 음성(B) 업그레이드 (조립형 검증 후)
- 무한 페르소나 커스텀
- 네이티브 iOS/Android 앱
- 푸시 알림 (특히 iOS 제약)
- 결제·대규모 계정 시스템
- 고급 분석/대시보드

## 14. 리스크 & 확장 시 점검 항목

- **개인정보·컴플라이언스**: 미성년자 음성·개인정보가 해외 API로 전송됨. 상용화 시 개인정보 처리방침·보관기간·데이터 레지던시·API의 "학습 미사용" 약관을 반드시 점검. (MVP=두 딸 한정에선 허용)
- **STT 정확도**: 한국식 발음 영어 인식 정확도 — STT 엔진 선택 시 실측 필요.
- **응답 지연**: 조립형 2~3초 체감. 스트리밍·로딩 연출로 완화.
- **비용**: 대화량 증가 시 토큰·음성 분당 비용 추적 필요.
